第一个问题答案很干脆——Claude Code 没有单独的会员，你买的是 Claude 的订阅。第二个问题麻烦一些，而且往往才是真正卡住人的地方。

## 先厘清一件事：Claude Code 没有独立套餐

Anthropic 把 Claude Code 打包进了 Claude 的付费订阅里。从 Pro 这一档开始，往上每一档都包含 Claude Code；只有免费档不带。所以查 Claude Code 的价格，本质上是查 Claude Pro 和 Claude Max 的定价，再加上一个问题：你打算用多少。

这一点值得先讲清楚。因为网上有些写法的措辞让人以为存在一个「Claude Code 专属月费」，实际上你付的钱和 Claude 网页版、桌面端用的是同一笔订阅费，额度也是从同一个池子里出。

## 「20 倍用量」到底指什么

这是整个价格体系里最容易被误解的地方。Claude 的付费订阅受两层限制：一层是 5 小时滚动窗口，限制你在一次会话里能烧多少；另一层是每周总额度，限制你 7 天内的总量。两层独立生效，哪个先撞上就先卡住你。

Anthropic 2025 年 7 月发给订阅用户的邮件里给过每周的参考数字（TechCrunch 当时也引用过）：

- Pro（$20/月）：40–80 小时 Sonnet 4
- Max 5x（$100/月）：140–280 小时 Sonnet 4，外加 15–35 小时 Opus 4
- Max 20x（$200/月）：240–480 小时 Sonnet 4，外加 24–40 小时 Opus 4

拿 Sonnet 的上限来算：Pro 是 80 小时，Max 20x 是 480 小时，比值是 6 倍，不是 20 倍。20 倍这个倍率成立的地方是 5 小时窗口那一层。日常真正让人停下来买额外用量的，往往是周额度。

这个口径差异后来演变成了实际争议——有媒体报道，一位叫 Karl Kahn 的开发者就其声称的用量不符，在加州北区联邦法院提起了集体诉讼，争议焦点正是「20x」对应的到底是哪一层限制。另外，Anthropic 自己在 2025 年 8 月上线的周额度限制，官方估算影响不到 5% 的订阅用户，但对每天跑 Claude Code 的人来说，这个限制是能感知到的。

你不需要记住诉讼细节，只需要记住结论：**Max 5x 和 Max 20x 之间的 100 美元差价，买的不是「4 倍」，而是「更少被打断」。** 值不值，取决于你被限额打断的频率。

## 常见问题

**Claude Code 有免费版吗？**
没有。免费档不含 Claude Code，最低需要 Pro。

**买了 Pro 就一定能在终端里跑 Claude Code 吗？**
可以，Claude Code 从 Pro 起全面包含。但你要自己准备能连上的网络环境。

**API 按量付费是不是更便宜？**
不好一概而论。按量计费适合用量波动大、或者只在 CI 里跑的人；每天固定交互式写代码的话，订阅的固定成本更容易预估。Anthropic 也留了溢出通道：订阅额度用完后可以开 usage credits，按 API 价继续用。

**年付值得吗？**
只有 Pro 有年付，$200 一次性付掉换 $17/月，比月付省 $36。Max 没有年付，别等。

**国内账号会有封号风险吗？**
风险主要来自环境异常本身——IP 频繁跳、DNS 泄露、指纹和 IP 地区对不上，这些在官方渠道和其它渠道都一样会被风控盯上。反过来，IP 相对固定、环境干净、不违反使用条款，绝大多数用户长期使用是正常的。
